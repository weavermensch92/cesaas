============================================
  HD건설기계 Sensor Extension — 설치 안내
============================================

[빠른 설치 — 1 클릭]

  1. install.bat 더블클릭
  2. Chrome 시작 여부 선택
  3. 끝.

  → 바탕화면 'HD Sensor Chrome' 바로가기 생성됨.
  → 이후 사용 시 이 바로가기로 Chrome 열기.

[작동 방식]

  - 일반 Chrome 과 별도 프로필 (전용 캡쳐 환경)
  - 위치: %LOCALAPPDATA%\HDSensor
  - 프로필: %LOCALAPPDATA%\HDSensor-Profile
  - Bitrix24 (또는 등록된 CRM) 접속 시 자동 캡쳐
  - 오프라인 시 IndexedDB 큐로 대기, 온라인 복귀 시 자동 송출

[Extension 아이콘 핀 고정]

  Chrome 창 우측 상단의 퍼즐 아이콘 클릭
  → "HD Sensor" 옆 압정 아이콘 클릭 → 상시 표시

[설치 위치]

  설치 폴더    %LOCALAPPDATA%\HDSensor
  프로필 폴더  %LOCALAPPDATA%\HDSensor-Profile
  바로가기     바탕화면 "HD Sensor Chrome"

[제거]

  uninstall.bat 더블클릭 → 확인 후 모두 삭제.

[문제 해결]

  · "Chrome 발견 안 됨" → Chrome 설치 후 install.bat 재실행
  · "캡쳐 안 됨" → 바로가기로 Chrome 시작했는지 확인
                  (일반 Chrome 으로 열면 작동하지 않음)
  · "큐 적체" → Chrome 우측 퍼즐 > HD Sensor 아이콘 클릭 →
              큐 상태 확인. 인터넷 연결 안정성 점검.

[발급 정보]

  Key ID       __KEY_ID__
  Dealer ID    __DEALER_ID__
  발급 시각    __ISSUED_AT__
  발급자       __ISSUED_BY__
