============================================
  HD Construction Equipment — Sensor
  Расширение для Chrome — инструкция
============================================

[Быстрая установка — 1 клик]

  1. Дважды кликните install-ru.bat
  2. Выберите, запускать ли Chrome сейчас
  3. Готово.

  → На рабочем столе появится ярлык 'HD Sensor Chrome'.
  → В дальнейшем открывайте Chrome через этот ярлык.

[Как работает]

  - Отдельный профиль Chrome (изолированная среда захвата)
  - Папка: %LOCALAPPDATA%\HDSensor
  - Профиль: %LOCALAPPDATA%\HDSensor-Profile
  - Автозахват при заходе в Bitrix24 (или другой настроенный CRM)
  - При отсутствии интернета — очередь в IndexedDB, отправка при восстановлении

[Закрепить иконку расширения]

  В правом верхнем углу Chrome — значок пазла
  → Кнопка-кнопка рядом с "HD Sensor" → значок будет виден всегда

[Папки установки]

  Установка   %LOCALAPPDATA%\HDSensor
  Профиль     %LOCALAPPDATA%\HDSensor-Profile
  Ярлык       Рабочий стол → "HD Sensor Chrome"

[Удаление]

  Запустите uninstall-ru.bat → подтвердите.

[Устранение проблем]

  · "Chrome не найден"
      → Установите Chrome и запустите install-ru.bat заново.
  · "Захват не работает"
      → Убедитесь, что Chrome открыт через ярлык "HD Sensor Chrome"
        (обычный Chrome не подойдёт).
  · "Очередь не отправляется"
      → Откройте значок HD Sensor в Chrome → проверьте статус очереди.
        Проверьте подключение к интернету.

[Данные расширения]

  Key ID       __KEY_ID__
  Dealer ID    __DEALER_ID__
  Выдано       __ISSUED_AT__
  Кем выдано   __ISSUED_BY__
