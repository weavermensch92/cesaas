## 5. LLM 보조 (Q8' 자유응답)

- **모드**: 서버 비동기 (Edge Function — 부스 즉시성 불필요)
- **프롬프트**: R_10.06 PromptTemplates의 `dw_extraction_q8` (후속 추가 — Phase B+)
- **출력**: `{ "dw_partial": {...}, "confidence": 0~1, "rationale": "..." }`
- **반영**: confidence ≥ 0.6 → 룰 0.7 + LLM 0.3 가중 평균. < 0.6 → 무시.
- **fallback**: 자유응답 빈/오류 → Q3'~Q7' 5문항만으로 산출
