## 1. TL;DR

- **차원**: 8 segment × 6 DW (`price·fuel·durability·service·reference·versatility`)
- **값**: 0.0~1.0 float — HD가 segment에서 해당 축으로 어필할 자산 강도
- **저장 위치**: `R_10.01_LeadScoring.yaml`의 `hd_strength_matrix` 절 + DB rule_versions
- **사용**:
  - R_10.01.005 `dw_alignment_bonus` 내적 (응답 normalized_pref_axes × hd_strength[segment])
  - R_10.07 DealerOutput의 `dw_emphasis` (segment별 상위 2축) 자동 산출

## 3. 산출·해석

### LeadScoring 가산 (R_10.01.005)
```
normalized = { k: (v - 1) / 4 for k, v in response.preference_axes }
alignment  = dot(normalized, hd_strength[lead.segment])  # 0~6
bonus      = clip(round(alignment * 2.5), 0, 15)
score     += bonus
```

예 (mining 고객, preference_axes = `{price:2, fuel:5, durability:4, service:2, reference:3, versatility:1}`):
- normalized = `{price:0.25, fuel:1.0, durability:0.75, service:0.25, reference:0.5, versatility:0.0}`
- alignment = 0.25·0.4 + 1.0·0.9 + 0.75·0.9 + 0.25·0.6 + 0.5·0.7 + 0.0·0.3 = 2.225
- bonus = round(2.225 × 2.5) = 6 → LeadScore +6
