## 1. TL;DR

- **이름**: DecisionWeight (DW) — 한국어 "결정 가중치 6축"
- **6 ID**: `price · fuel · durability · service · reference · versatility`
- **저장**: `responses.preference_axes` JSONB (1~5 정수, prd-v1 기존 스키마)
- **내부 산출**: 0~1 float (R_10.10) → 1~5 정수로 변환 후 저장
- **산출**: 간접 5질문 (V_50.09) → R_10.10 룰 / 또는 딜러 직접 입력 (025 마이그레이션 경로)
- **노출**: V_10 Dealer 부스 · V_30 Voice Admin · S_50 Sensor Admin

## 2. 6축 매트릭스

| # | ID | 한국명 | 정의 | 영업 시 의미 |
|---|---|---|---|---|
| 1 | `price` | 가격 경쟁력 | 초기 구매가·금융 조건·할인 | 가격 프로모션·금융 패키지 |
| 2 | `fuel` | 연료 효율성·가동 시간 | 연비·MTBF·연간 가동률 | TCO 시뮬레이션·가동률 검증 자료 |
| 3 | `durability` | 내구성·신뢰성 | 고장 빈도·엔진 수명·잔존가치 | 5,000h 엔진 보장·잔존가치 보증 |
| 4 | `service` | 서비스 네트워크 | 부품 조달·24h 대응·정비망 | 권역 서비스망·SLA |
| 5 | `reference` | 프로젝트 레퍼런스 | 대규모 현장 실적·브랜드 인지도 | 레퍼런스 카탈로그·현장 영상 |
| 6 | `versatility` | 다목적 활용성 | 옵션 다양성·다현장 호환 | 신모델 데모기·옵션 패키지 |

## 3. 도메인·정규화·변환

| 항목 | 값 |
|---|---|
| DB 저장 도메인 | int 1~5 (`responses.preference_axes`) |
| R_10.10 내부 산출 | float 0~1 |
| 1~5 → 0~1 정규화 (R_10.01.005 입력) | `(v - 1) / 4` |
| 0~1 → 1~5 변환 (R_10.10.005 출력) | `clamp(1 + round(4 * v), 1, 5)` |
| UI 표시 | 1~5 그대로 (또는 0~5 Radar 컴포넌트에서 `v - 1`로 0~4 매핑) |
| 무응답 prior | 0.5 (0~1) ↔ 3 (1~5) |

## 5. CA (기존 분류 6 axis)와 차이

| 항목 | CA (기존 R_10.05 입력) | DW (본 문서) |
|---|---|---|
| 본질 | 고객 분류 — 어떤 종류 고객인가 | 고객 선호 — 무엇을 중시하는가 |
| 컬럼 | `responses.axis_data` | `responses.preference_axes` |
| 점수 | enum·범주 | 1~5 정수 |
| 산출 | 직접 질문 6개 (Q1~Q6 6 axis) | 간접 5+자유응답 1 → R_10.10 추론 또는 딜러 직접 입력 |
| 사용처 | R_10.05 8 segment 매칭 | R_10.07 dw_emphasis sales_weapons 정렬 · R_10.01.005 LeadScoring 가산 |

두 축은 **병행** 운영. 응답 1건에 둘 다 저장.

## 6. 평균 산출식

- 응답 다건 평균 (entity 통합):
  ```
  leads.dw_alignment = dot(normalized_pref_axes, hd_strength[segment])  # 0~6
  ```
- segment 평균 (V_30.03 Insight v0 집계):
  ```sql
  AVG((preference_axes->>axis)::int) FILTER (WHERE segment = $1)
  ```
