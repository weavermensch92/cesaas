## 1. TL;DR

- **입력**: 간접 5질문 (Q3'~Q7') + Q8' 자유응답
- **출력**: `preference_axes = {price, fuel, durability, service, reference, versatility}` (1~5 정수, DB 저장)
- **내부 산출**: dw_normalized 0~1 float → R_10.10.005 변환으로 1~5 정수
- **모드**:
  - 룰 모드 — V_50.09 매트릭스로 클라이언트 즉시 산출 (오프라인 가능)
  - LLM 보조 — Q8' 자유응답을 서버 비동기 LLM으로 추출, confidence ≥ 0.6이면 가중 평균
- **저장**: `responses.preference_axes` (값) + `responses.dw_raw_answers` (원응답) + `responses.dw_extraction` (메타)

## 3. 룰 모드 (Q3'~Q7' 5문항)

### 알고리즘
```
1. V_50.09 매트릭스 로드 M[question][choice][axis] = weight
2. 각 질문 응답 → 보기 가중치 추출
3. 다중 선택 (Q4'·Q7') → 선택 보기 평균
4. dw_normalized[axis] = sum(질문별 가중치) / max(응답한_질문수, 1)
5. 누락 축 prior = 0.5
6. clamp [0, 1]
7. preference_axes[axis] = clamp(1 + round(4 * dw_normalized[axis]), 1, 5)
```

### 의사코드 (TypeScript)
```typescript
function computeDw(input: DWInput, matrix: DWMatrix): { dw_normalized: Record<DWAxis, number>; preference_axes: Record<DWAxis, number> } {
  const axes: DWAxis[] = ['price', 'fuel', 'durability', 'service', 'reference', 'versatility'];
  const sums = Object.fromEntries(axes.map(a => [a, 0]));
  const counts = Object.fromEntries(axes.map(a => [a, 0]));

  for (const q of ['q3_prime', 'q4_prime', 'q5_prime', 'q6_prime', 'q7_prime'] as const) {
    const choices = Array.isArray(input[q]) ? input[q] : (input[q] ? [input[q]] : []);
    if (choices.length === 0) continue;
    for (const axis of axes) {
      const avg = choices.map(c => matrix[q][c][axis]).reduce((a, b) => a + b, 0) / choices.length;
      sums[axis] += avg;
      counts[axis] += 1;
    }
  }

  const dw_normalized = Object.fromEntries(
    axes.map(a => [a, counts[a] > 0 ? clamp(sums[a] / counts[a], 0, 1) : 0.5])
  );
  const preference_axes = Object.fromEntries(
    axes.map(a => [a, clamp(1 + Math.round(4 * dw_normalized[a]), 1, 5)])
  );

  return { dw_normalized, preference_axes };
}
```

## 4. LLM 보조 모드 (Q8' 자유응답)

### 트리거
- `length(q8_prime) > 5`
- 서버 비동기 큐 enqueue (Edge Function — 부스 즉시성 영향 없음)

### 프롬프트 (`dw_extraction_q8` — R_10.06 후속 추가)
```
응답: "{q8_text}"

위 응답에서 다음 6 속성이 고객 구매 결정에 얼마나 비중을 차지하는지 0~1로 추정:
- price · fuel · durability · service · reference · versatility

JSON 출력: { "dw_partial": {...}, "confidence": 0~1, "rationale": "..." }
```

### 갱신 규칙
- `confidence ≥ 0.6` → `dw_normalized = 0.7 × rule_result + 0.3 × llm_partial` → preference_axes 재변환
- `confidence < 0.6` → 무시 (`dw_extraction.method = 'rule_only_low_llm_confidence'`)
- Q8' 빈/오류 → 룰 모드만

### 저장
```json
responses.dw_extraction = {
  "method": "rule" | "rule+llm" | "rule_only_low_llm_confidence",
  "rule_version": "R_10.10 v1",
  "llm_run_id": "uuid|null",
  "llm_confidence": 0.0-1.0|null
}
```

### Edge Function (TypeScript — 후속 구현 예정)
```typescript
import { loadRule } from '../../C_Common/packages/core/src/rules.ts';
import { computeDw } from '../../C_Common/packages/core/src/decision_weight.ts'; // 후속 추가

// 응답 수신 시
const { body: dwRule } = await loadRule('R_10.10_DecisionWeight');

const { dw_normalized, preference_axes } = computeDw(dwInput, dwRule.weight_matrix);

await db.responses.update({
  id: response.id,
  preference_axes,
  dw_raw_answers: dwInput,
  dw_extraction: {
    method: 'rule',
    rule_version: 'R_10.10 v1',
    llm_run_id: null,
    llm_confidence: null,
  },

// Q8' 있으면 LLM 비동기 큐
if (dwInput.q8_prime && dwInput.q8_prime.length > 5) {
  await llmQueue.enqueue({ kind: 'dw_q8', response_id: response.id });
}
```
